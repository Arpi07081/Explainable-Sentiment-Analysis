Project Name: Explainable Sentiment Classifier

Project Description:
Explainable Sentiment Classifier. Build an explainable sentiment classifier. You can rely on
the classic NLP pipeline (tokenization, stopword removal, lemmatization) as well as on the use
of TF-IDF and static embeddings. You can use Logistic Regression or other ML techniques.
WordNet can be used (synonyms, antonyms) to enrich feature vectors. Two versions can be
addressed and be conveniently tested: one based on simple polarity classification
(positive-negative) and other with more fine grained emotions. The key of this project is to make the final decision explainable (i.e., given a result, the reasons that led to such a result should be also informed to the user).
